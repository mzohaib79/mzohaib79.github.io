Patterns you will find in the code

Service and repository layers
Controllers call services, and services depend on repository interfaces. A service provider binds the Eloquent implementations. See UserService, UserRepositoryInterface and RepositoryServiceProvider.
Events and listeners
Side effects such as notifications are decoupled from the request. NewUserCreated triggers NotifyUser.
Migrations and seeders
The database schema is versioned in code and reproducible, for example the file, column and data tables behind the Excel importer.
Authentication flows
Registration, login, password reset and email verification, as in stage-two-screening.
